# Task 2 requirements and implementation map

Ground truth: [assignment manual](../ATML-PA3.pdf), Task 2, pp. 7–10. This is an implementation record, not report analysis. All model-interface, adapter, training, selection, recovery, decoding and scoring code was written for this repository. Libraries provide pretrained architectures, tensor operations, tokenization, image preprocessing and transport. No external VLM trainer, public assignment solution, PEFT adapter implementation, or external VQA scorer is used.

| Manual requirement | Implementation |
| --- | --- |
| Original Qwen3-0.6B, thinking disabled, original weights frozen | `model.py`: pinned starting revision, native chat template with `enable_thinking=False`, frozen language parameters |
| Frozen SigLIP, 196 row-major final patches, final norm exactly once | `features.py`: `SiglipVisionModel.last_hidden_state` already includes `post_layernorm`; no second normalization; deterministic official processor; FP16 atomic shards |
| Trainable 768→1024→1024 GELU connector throughout | `model.py`: original two-layer MLP, FP32 master parameters, fixed training-only RMS calibration scale |
| Visual embeddings inside user message before question; matching masks/labels/positions | `model.py`: native template token boundary, inserted patch embeddings; left padding and recomputed positions; no-image removes patches and reconstructs all masks |
| Seed 6304; save all IDs; train2014 vs val2014; all evaluation sets image-disjoint | `data.py`: seeded source selection, explicit pair/answer/image/caption IDs, global evaluation image exclusion, isolation assertions |
| Captions 6000×3 / 96×1 | Source captions filtered for content cap before selection; exactly 18,000 training examples, two shuffled passes in Stage 1 |
| Annotation presence/count pairs | COCO instances → templates and different-answer pairs; only noncrowd category counts 1–4; absence requires no annotation for that category; evaluation 12+12 dev / 32+32 test pairs |
| Reusable grounding training pools | 4,096 pairs per type, generated on the union of selected caption/natural training images; repeated sampling permitted; no fixed per-batch quotas |
| Natural complementary consensus ≥8/10, differing normalized answers | Official pair lists and all ten official answers; same raw question and answer type; target is the first original string in the normalized consensus group |
| Natural pair quotas 640/256/640, 12/8/12, 36/24/36 | Explicit selection quotas in `data.py`, audited by answer type; dev/test pairs additionally use distinct image IDs |
| Question 80, caption 64, short target 16 content tokens | Eligibility filtering before selection; original targets are not truncated; EOT supervised separately |
| 2250 / 1500 / 750 applied updates; effective batch 16 | `config.py`, `training.py`: microbatch 8×2, exactly 4500 applied steps / 72,000 presentations; no budget adjustment for hardware |
| AdamW .01, clip 1 after unscale, stage LRs, warmup/cosine | `training.py`: FP32 moments/trainables, frozen FP16 Qwen, CUDA FP16 autocast/dynamic GradScaler; exact stage peaks; ceil(5%) warmup, cosine ending at .1 peak |
| Mean token loss per example, then mean over examples; EOT included | `model.py`: response-only vocabulary projection, unreduced CE, per-example normalization, two equally sized microbatch losses divided by 2 |
| Stage 2/3 pair-preserving random mixtures | `data.Sampler`: eight independent component draws per effective batch; each yields one intact pair or two caption examples; deterministic sampler state saved |
| Own LoRA: rank16/alpha32/dropout.05/q,k,v,o/no biases | `model.LoRALinear`: A uniform ±1/√in, B zero, private seeded initialization; introduced only after Stage 1; same adapter weights continue into Stage 3 |
| Checkpoints every250; stage endpoint weights | `training.py`: atomic checkpoint-directory commit with SHA-256 receipts; original frozen backbones need not be duplicated; all 18 prescribed checkpoints plus initial state retained |
| Recovery incl. optimizer, scheduler, scaler, sampler, stage and RNG | Trusted recovery payload includes complete progress, RNG, caption permutation, optimizer moments, scheduler definition/position, scaler, history and counts; original model revisions/split/cache/protocol bind restores |
| Development at0/every500/stageends | `cli.next_step`: evaluations at 0,500,1000,1500,2000,2250,2500,3000,3500,3750,4000,4500; missing due evaluations completed before further training |
| Dev caption loss; correct/partner/no-image VQA NLL and swap penalty | `evaluation.py`, `summary.py`: caption CE includes EOT; answer reference NLL excludes EOT, mean tokens then examples; swap penalty is partner minus correct |
| Final Stage3 only; greedy16, batch8, four image conditions | `evaluation.py`: only checkpoint4500; correct/complementary/mismatched/no-image; references and question remain original in every control |
| Mismatch mapping fixed before generation, excludes original pair | `data.fix_mismatches`: seeded mapping saved in selection; both mismatched images belong to another pair in the same final suite |
| Normalized EM / ten-answer local VQA soft score | `metrics.py`: consistent public normalization semantics across selection/scoring; independent leave-one-out soft score; empty outputs retained |
| Pair accuracy, identical/empty rates, NLL/time, partner following | `metrics.py`, per-example journals and tables; identical answers use normalized strings; pair accuracy means both canonical originals match |
| 4000 complete-pair bootstraps; matched differences | `metrics.bootstrap`, `summary.py`: sample whole two-example pairs; one seed and ordered pair IDs across conditions; accuracy correct−partner and NLL partner−correct |
| Runtime/peak memory/trainables/cache costs/raw outputs | Stage measurements and per-example generation time; cache costs stored separately; package versions, GPU, Git head, source hashes and source archives recorded |
| Learning curves and aligned examples with selection rule | Summary produces curves/stage boundaries, tables and embedded-image HTML; first two selected pairs per answer type fixed independently of results |
| Inspect annotation labels independently of predictions | Separate embedded label worksheet and human CSV; audit does not fabricate completed reviews |

Choices where the manual leaves details open: Python's seeded sampler, unique evaluation images within each suite, equal presence/count evaluation split, 4,096 grounding pairs per training component, eligibility filtering rather than target truncation, training-only calibration on the first 64 unique selected caption images, fresh optimizer/scaler at stage transitions, AdamW default betas/epsilon, and separate ordinary VQA instruction text. These choices are frozen in source and saved protocol before training. Only the required 196-token run is exposed as an experiment; the optional 49-token full repeat is not part of the main workflow.

## Validation

`python -m atml.task2 smoke` uses randomly initialized tiny Qwen/SigLIP architectures, a synthetic chat tokenizer, synthetic annotations and a fake remote store. It checks causal loss against dense CE, equal example weighting, connector gradients through frozen Qwen, FP32 adapters and their target scope, left-padded cached generation against individual generation, final vision normalization, spatial pooling, VQA scoring, deterministic selection, image isolation, pair-preserving draws, stage schedules, exact optimizer/RNG continuation, atomic checkpoints, backup failure handling, hash verification, fresh-disk restore and journal scope checks. All fixtures live in a temporary directory and are removed on exit. No synthetic artifacts are stored under real Task 2 evidence.

Local verification is CPU-only on Apple Silicon. No real data, pretrained weights or full experiment were downloaded or run for these tests. Run `doctor` and `smoke` on the rented machine, then execute the fixed GPU recipe. Full FP16 training, HTTP/Hub connectivity, actual data eligibility, runtime and GPU peak memory have not been measured locally. The 4090 execution profile uses selective nonreentrant checkpointing (cache mm/bmm/addmm), 512-token response projections, bounded GPU feature residency, batch-32 development likelihood and batch-512 vision extraction with OOM fallback. None changes the manual's microbatch 8, accumulation 2, or final batch 8.

Primary API/data specifications used: [VQAv2 official downloads](https://visualqa.org/download.html), [VQA normalization/scoring specification](https://visualqa.org/evaluation.html), [Transformers 4.51.3 SigLIP API](https://huggingface.co/docs/transformers/v4.51.3/en/model_doc/siglip), [Transformers 4.51.3 Qwen3 API](https://huggingface.co/docs/transformers/v4.51.3/en/model_doc/qwen3). Pretrained architecture/library API inspection was used to establish the normalization and cache interfaces, not to copy a training pipeline.
